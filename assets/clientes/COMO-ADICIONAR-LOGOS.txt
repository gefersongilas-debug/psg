PSG / Página Clientes — arquivos oficiais de marca pendentes

A página /clientes/ está completa e responsiva com 31 assinaturas tipográficas que mostram os nomes corretos das organizações (17 empresas + 14 escritórios). Elas NÃO são logotipos oficiais.

Para substituir por logos oficiais após autorização do cliente:
1. Peça ao cliente as versões SVG ou PNG transparente de cada marca.
2. Guarde os arquivos nesta pasta (assets/clientes/).
3. Troque o <span class="client-brand-name">NOME</span> do card correspondente em clientes/index.html por:
   <img class="client-brand-logo" src="../assets/clientes/logo-oficial.svg" alt="Nome da organização" loading="lazy" decoding="async">
4. Adicione ao final de style.css:
   .client-brand-logo { width:100%; height:70px; object-fit:contain; }
   .clients-brand-grid-dark .client-brand-logo { filter:grayscale(1) brightness(0) invert(1); }
5. Confirme nomes, autorização de uso e que a categoria comercial descreve a relação corretamente.

Não há dependências externas para as logos provisórias. Nunca use a logo de outra marca como substituta.
